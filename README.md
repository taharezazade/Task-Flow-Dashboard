# 🚀 TaskFlow

A modern project management platform inspired by industry-leading workflow tools. TaskFlow helps teams organize workspaces, boards, tasks, and team collaboration in a fast and intuitive environment.

## 📖 Overview

TaskFlow is a full-stack project management application designed to help individuals and teams manage projects efficiently.

The platform provides an intuitive drag-and-drop interface, workspace management, task tracking, activity logs, authentication, and responsive user experience across devices.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/taskflow.git
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm run dev
```

## 🌍 Environment Variables

Create a `.env` file inside the server directory:

```env
DATABASE_URL=
JWT_SECRET=
PORT=5000
```
